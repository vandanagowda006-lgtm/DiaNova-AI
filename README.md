## 🌟 About DiaNova AI

DiaNova AI is an intelligent healthcare-oriented web application that combines diabetes prediction with personalized wellness support.

Powered by a trained Machine Learning model and an AI-driven wellness companion, the platform transforms user-provided health information into accessible prediction results, interactive insights, and general lifestyle guidance.

**More than a prediction system — a smarter approach to everyday wellness.**

## 🚀 Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/DiaNova-AI.git
cd DiaNova-AI
```

**2. Create a virtual environment**

```bash
python -m venv venv
venv\Scripts\activate
```

**3. Install dependencies**

```bash
pip install -r requirements.txt
```

**4. Configure required API secrets**

Add the required credentials to your local Streamlit secrets configuration. Never commit private API keys.

**5. Launch DiaNova AI**

```bash
streamlit run app.py
```
